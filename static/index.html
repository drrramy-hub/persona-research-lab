EVIDENCE FIRST. PEOPLE ALWAYS.

Explore perspectives.
Stay close to the evidence.

Build provisional persona agents from qualitative excerpts. Review their foundations, explore questions, and take the unknowns back to real participants.

Simulated responses are not participant evidence. This tool supports researcher interpretation; it does not conduct interviews or validate personas.

Start with the fictional sample or add anonymised records.

01 / Prepare your evidence

Use 2–60 records, each with a unique id and text. Remove names and identifying details before upload. Anonymisation is your responsibility; this app does not perform it.

Live analysis uses one model call. Comparing personas uses one call per persona, up to three. Azure charges may apply.

02 / Review the interpretations

Proposed themes, exact excerpts and persona cards will appear here.

Edit the proposed analysis as JSON

Source matching checks text and IDs only. It cannot establish that the interpretation is justified.

04 / Export your working record

Exports include supplied evidence, reviewed analysis and explicitly labelled simulations. Save only where you are authorised. Refreshing this page clears the session.
